## 그리는 규칙 (강의안 형식)

STEP 3 두 장은 **교재 Day5 p.73 의 순서도 형식**을 따른다. 9/7 에 이 형식으로 다시 그렸다.

- **상자 하나에 짧은 한 줄.** 설명 문장을 상자 안에 넣지 않는다. 그래서 상자가 좁고 한눈에 읽힌다.
- **판단은 마름모 + `Y` / `N`.** 되돌아가는 가지는 오른쪽으로 빼서 이전 상자로 잇는다.
- **설명은 그림 밖으로.** 예외 처리는 태그만 붙이고 내용은 그림 아래 표에 적는다.
- **토픽 이름과 메시지 타입만 화살표 위에 적는다.**
- 흐름이 길면 두 단으로 접고 `①` 로 잇는다.

바꾸기 전 `step3_scenario` 는 1320×2011 에 가로 456 px 짜리 설명 상자였고, 지금은 1180×1067 이다.

## 고치는 법

그림은 **손으로 그리지 않고 스크립트가 만든다.** 좌표·상자 크기·연결선이 자동으로 맞춰지고,
문서와 값이 어긋나면 한 곳만 고치면 되기 때문이다.

```bash
# 내용을 고친 뒤
python3 tools/build_diagrams.py
```

스크립트는 글자가 상자 밖으로 넘치는지, 상자가 캔버스를 벗어나는지 검사해 경고한다.

draw.io 에서 직접 손볼 일이 있으면 `mro_design_diagrams.drawio` 를 열어 편집하고,
**그 결과를 스크립트에도 반영한다.** 반영하지 않으면 다음 생성 때 되돌아간다.
