## 규칙

- **여기가 원본이다.** 노션은 팀이 읽는 사본이고, 이 파일을 올린 것이다. 노션에서 고치지 않는다.
- **버전마다 새 파일**을 만든다 (`..._v0.15.md`). git 이 이력을 갖지만 **노션 페이지와 팀의 인용이 버전 번호로 되어 있어** 파일명을 맞춘다.
- 내용이 더해지거나 값이 바뀌면 **minor 를 올리고 문서 안 변경 이력에 한 줄** 남긴다. 오탈자·서식만 고칠 때는 올리지 않는다.
- **버전을 올리면 노션에도 같은 버전의 하위 페이지를 만든다.** 노션이 늦으면 팀이 옛 문서를 본다.
- 제출본은 **BRD·SDD 모두 최종본을 9/11 09:30** 에 Google Drive 로.

## 왜 저장소로 옮겼나

저장소 밖에 있는 동안은 "무엇이 최신인지" 를 구분할 방법이 버전 번호뿐이었다 (`AGENTS.md` 문서 규칙). 이제 git 이 이력을 가지므로 **코드 변경과 문서 변경이 같은 커밋 이력에 남는다** — 계약을 올린 커밋과 SDD 를 올린 커밋을 나란히 볼 수 있다.
