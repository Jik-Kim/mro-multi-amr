# WebCam2 SLAM 캘리브레이션 지점

WebCam2 호모그래피를 다시 계산할 때 사용한 픽셀–SLAM `map` 대응점 13개이다. 맵 좌표는 각 픽셀 지점에 TurtleBot4를 정차한 뒤 **LiDAR 중심을 기준으로 AMCL에서 읽은 값**이다. 원본 로봇 pose 로그는 `robot4_fromLiDAR2.txt`, 계산 결과는 `homography_cam2.json`에 보존한다.

## 9/7 실주행 확인

`webcam2.py`에서 영상 픽셀을 호모그래피로 map `(x, y)` 좌표로 변환하고 `/robot8/navigate_to_pose`로 목표를 보냈다. 로봇의 실제 도착 위치에서 약 **15 cm 오차**가 관찰돼 시험을 중단했다.

- 재투영 RMSE: 0.0284 m
- 실주행 관찰 오차: 약 0.15 m
- 현재 상태: 원인 미분리, TS-U02 재검증 필요
- 후속 확인: 픽셀 지정 오차, AMCL 정차·읽기 오차, Nav2 목표 도착 제어 오차를 각각 분리해 측정
