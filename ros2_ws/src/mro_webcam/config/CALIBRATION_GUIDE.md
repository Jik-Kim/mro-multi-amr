# WebCam2 캘리브레이션 사용 가이드

## 1. 개요

`calibrate_cam2_markers` GUI는 WebCam2 이미지의 픽셀 좌표와 ROS map 실좌표를
연결해 homography를 계산한다. 캘리브레이션에 사용한 이미지, 포인트 확인용
이미지, JSON 결과를 항상 하나의 폴더로 관리한다.

실측 좌표는 GUI에서 **mm 단위로만 입력**한다. ROS map 좌표 계약은 m 단위이므로
프로그램이 mm를 m로 변환해 계산하고 JSON에 저장한다.

## 2. 실행 준비

최초 1회 또는 코드 변경 후 패키지를 빌드한다.

```bash
cd <mro-multi-amr>/ros2_ws
source /opt/ros/jazzy/setup.bash
colcon build --packages-select mro_webcam --symlink-install
source install/setup.bash
```

GUI를 실행한다.

```bash
ros2 run mro_webcam calibrate_cam2_markers
```

기본 카메라 해상도는 640×480이다. 필요하면 실행 시 변경할 수 있다.

```bash
ros2 run mro_webcam calibrate_cam2_markers --width 1280 --height 720
```

## 3. 시작 창

시작 창은 `불러오기`와 `라이브` 두 탭으로 구성된다. 기본 탭은
`불러오기`다.

### 불러오기 탭

이미지와 JSON을 각각 독립적으로 선택한다.

- `마커 이미지`: 필수다. PNG, JPG, JPEG, BMP를 선택할 수 있다.
- `기존 실좌표 JSON 불러오기`: 선택 사항이다.
- 기본값은 현재 `config/WebCam2/reference.png`와 `homography_cam2.json`이다.

이미지에 민트색 3×3 px 마커가 있으면 자동으로 검출한다.

#### 이미지 + JSON

JSON 불러오기를 선택하고 이미지와 JSON을 각각 지정한다. 이미지에서 검출한
마커와 JSON의 기존 픽셀 좌표를 비교해 가장 가까운 실좌표를 연결한다.

기존 캘리브레이션의 좌표나 마커 위치를 수정할 때 사용한다.

#### 이미지만 사용

`JSON 불러오기` 체크를 해제한 뒤 이미지만 선택한다.

- 민트색 마커가 있으면 마커만 자동 검출한다.
- 검출된 마커의 실좌표는 `실좌표 미입력`으로 표시된다.
- 각 마커를 클릭해 X, Y 실좌표를 mm로 입력한다.
- 마커가 없는 일반 이미지는 빈 상태에서 직접 마커를 추가하면 된다.

### 라이브 탭

GUI가 `/dev/video*`를 확인해 연결된 카메라 인덱스를 콤보박스에 표시한다.
사용할 인덱스를 선택하고 `시작`을 누른다.

연결 인덱스는 다음 명령으로도 확인할 수 있다.

```bash
v4l2-ctl --list-devices
ls -l /dev/video*
```

## 4. 마커 편집

| 조작 | 동작 |
|---|---|
| 빈 위치 좌클릭 | 3×3 px 민트색 마커 추가 후 X, Y [mm] 입력 |
| 기존 마커 좌클릭 | 마커 선택 및 기존 실좌표 수정 |
| 기존 마커 우클릭 | 마커와 연결된 실좌표 삭제 |
| `▲` `▼` `◀` `▶` | 선택한 마커를 해당 방향으로 1 px 이동 |
| `Enter` 또는 `S` | Homography 계산 및 저장 |
| `Esc` 또는 `Q` | 저장하지 않고 종료 |

마커 미세 이동은 픽셀 좌표만 변경하며 입력한 실좌표는 유지한다. 마커는
이미지 경계 밖으로 이동할 수 없다.

## 5. 실좌표 입력

마커를 좌클릭하면 `X Y [mm]` 입력창이 열린다.

```text
125.0 340.0
```

쉼표로도 입력할 수 있다.

```text
125.0, 340.0
```

모든 마커의 실좌표는 같은 ROS map 원점과 축을 기준으로 측정해야 한다.
Homography 계산을 위해 최소 4개의 마커가 필요하며, 저장 전에 모든 마커의
실좌표가 입력되어 있어야 한다.

## 6. 저장 결과와 이력

저장이 완료되면 `config/WebCam2/`에 다음 세 파일이 생성된다.

```text
WebCam2/
├── reference.png
├── points.png
└── homography_cam2.json
```

- `reference.png`: 마커가 합성된 캘리브레이션 기준 이미지
- `points.png`: 마커 ID와 mm 실좌표가 표시된 확인용 이미지
- `homography_cam2.json`: 픽셀·map 대응점, homography, 재투영 오차, RMSE

`reference.png`에는 3×3 px 민트색 마커만 합성하며 빨간 원, 마커 ID,
실좌표 문자는 넣지 않는다. 이 주석들은 `points.png`에만 저장한다.
`불러오기` 탭의 마커 이미지로 `points.png`를 선택할 수 없다.

기존 `WebCam2` 폴더가 있으면 새 결과를 저장하기 전에 다음 형식으로 이름을
바꿔 보존한다.

```text
WebCam2_YYYYMMDD_HHMMSS/
```

같은 초에 이력이 중복되면 `_01`, `_02` 순번을 추가한다. 이전 설정을 수정하려면
`불러오기` 탭에서 이력 폴더의 `reference.png`와 `homography_cam2.json`을
각각 선택한다.

## 7. 오류 확인

### 카메라를 열 수 없음

다른 프로그램이 같은 카메라를 사용 중인지, 선택한 `/dev/videoN` 인덱스가
올바른지 확인한다.

### 민트색 마커가 자동 검출되지 않음

마커는 민트색 3×3 px를 기준으로 검출한다. JPG 압축, 색상 변형, 크기 변경으로
검출되지 않은 마커는 이미지에서 직접 클릭해 다시 추가한다.

### JSON의 실좌표가 연결되지 않음

이미지의 검출 마커와 JSON 픽셀 좌표가 15 px 이상 떨어지면 실좌표를 자동
연결하지 않는다. `실좌표 미입력`으로 표시된 마커를 클릭해 좌표를
다시 입력한다.

### 저장할 수 없음

마커가 4개 미만이거나 실좌표가 없는 마커가 있으면 저장하지 않는다. 경고창에
표시된 현재 마커 수와 좌표 미입력 수를 확인한다.
